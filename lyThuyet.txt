1. Babel 
	Javascript trong các version mới sẽ có các hàm mới, mà với các 
browser cũ có thể chưa hỗ trợ dẫn đến bị lỗi, khi đó Babel sẽ chuyển đổi 
mã Javascript thành một mã JavaScript cũ hơn để chạy được trên các môi 
trường hoặc trình duyệt chưa hỗ trợ các tính năng mới.

	Tuy nhiên Server phải tiêu tốn nhiều tài nguyên (CPU, RAM và thời 
gian xử lý) để Babel chuyển đổi mã nguồn mỗi lần chạy. 
2. Route 
	Khai báo route là định nghĩa URL nào sẽ được xử lý bởi hàm nào
khi client gửi request đến server.
3. EJS 
	Là một template engine cho Express, giúp tạo các trang HTML động 
bằng cách chèn mã JavaScript và dữ liệu từ server vào file HTML trước khi 
gửi về trình duyệt
