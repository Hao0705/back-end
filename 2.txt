1. 	JSON.stringify(): chuyển một object thành một chuỗi JSON
	Sử dụng khi cần lưu vào LocalStorage.
	Sử dụng khi cần gửi dữ liệu lên server bằng fetch.

2. 	JSON.parse(): khôi phục chuỗi JSON thành object hoặc array ban đầu.

3. 	Gửi dữ liệu lên server bằng: HTML<form> 
	Tại server sẽ dùng: express.urlencoded() để chuyển đổi dữ liệu sang object. Dữ liệu sẽ được gán vào req.body.

4. 	Gửi dữ liệu lên server bằng: fetch() + JSON.stringify()
	Tại server sẽ dùng: express.json() để chuyển đổi dữ liệu sang object. Dữ liệu sẽ được gán vào req.body.
